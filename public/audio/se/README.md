# SE格納場所

このフォルダにゲーム内SEの音声ファイルを配置してください。

## 推奨ファイル名

- `topic-reveal.mp3` — お題と秘密数字の発表
- `button.mp3` — 通常ボタン
- `ordering-start.mp3` — 並び替え画面への移動
- `reorder.mp3` — カードの並び替え
- `result-reveal.mp3` — 答えの発表

MP3を推奨します。ブラウザ間の互換性を広げる場合は、同名のWebMまたはOGGも併置できます。

音量差が大きくならないよう、各ファイルのピーク音量を揃えてください。長さの目安は、ボタンと並び替えが0.1〜0.3秒、お題発表が0.5〜1.5秒です。
